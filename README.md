# SillyTavern-Failed-Vector-Purger

SillyTavern 標準の **Vector Storage** 拡張機能で、ベクトル化が最後まで完了しなかったファイル（Data Bank / チャット添付ファイル）のベクトルだけを検出・削除する拡張機能です。

## 設計思想

ベクトル化そのものは標準機能に任せ、本拡張機能は「失敗したものを空に戻す」ことだけを担当します。

標準の Vector Storage は、ファイルのコレクションに **1 件でもチャンクが保存されていれば「ベクトル化済み」とみなして再処理しません**。
そのため、API エラーやタイムアウト、ブラウザのリロードなどで途中まで処理されたファイルは、不完全なまま放置されてしまいます。

本拡張機能はそのような不完全なコレクションだけを削除します。
削除後に標準機能の **Vectorize All**（ファイル）を実行すると、標準機能は空のコレクションのファイルだけを処理するので、
**完了済みのファイルはそのまま、失敗したファイルだけが再ベクトル化されます**。

```
[標準] Vectorize All ──> 一部のファイルが途中で失敗
[本拡張] 検査して削除 ──> 不完全なコレクションだけを空にする
[標準] Vectorize All ──> 空になったファイルだけを再ベクトル化
```

## 判定方法

各ファイルについて、標準機能と同じ手順（チャンクサイズ・オーバーラップ・区切り文字・ハッシュ関数）で
「本来保存されるべきチャンクのハッシュ集合」を計算し、実際に保存されているハッシュと比較します。

| 判定 | 意味 | 既定の扱い |
| --- | --- | --- |
| 完了 | 期待されるチャンクがすべて保存されている | 何もしない |
| 不完全 | 保存済みチャンクが期待値の一部しかない（＝途中で失敗） | **削除** |
| 設定不一致 | 期待しないチャンクが含まれる（チャンク設定の変更、翻訳オプションなど） | 何もしない（オプションで削除可） |
| 未ベクトル化 | コレクションが空 | 何もしない（標準機能が処理します） |
| エラー | ファイル本文の取得などに失敗 | 何もしない |

使用中の埋め込みソース・モデルの保存先を参照するため、標準 Vector Storage と同じ設定のまま実行してください。

## インストール

SillyTavern の拡張機能メニュー → **Install extension** に以下の URL を入力します。

```
https://github.com/GenesisOmniarch/SillyTavern-Failed-Vector-Purger
```

## 使い方

拡張機能パネルの **Failed Vector Purger** を開きます。

- **検査**: 現在のチャットで参照される全ファイル（グローバル / キャラクター / チャットの Data Bank、チャット添付）を検査し、結果を一覧表示します。削除はしません。
- **選択を削除**: 一覧でチェックしたコレクションを削除します。
- **検査して削除**: 検査を行い、削除対象をまとめて削除します。
- **再ベクトル化**: 標準 Vector Storage の「Vectorize All（ファイル）」を実行します。

### オプション

- **無効化された Data Bank ファイルも検査する**（既定: ON）
- **「設定不一致」も削除対象にする**（既定: OFF）— チャンク設定を変更して作り直したいとき用
- **削除後に標準機能の「Vectorize All」を自動実行する**（既定: OFF）
- **チャット切り替え時に自動で検査・削除する**（既定: OFF）

### スラッシュコマンド

```
/vector-purge-failed                 検査して不完全なベクトルを削除（削除件数を返す）
/vector-purge-failed dry=true        検査のみ（削除候補の件数を返す）
/vector-purge-failed revectorize=true  削除後に標準の Vectorize All を実行
/vector-purge-failed quiet=true      通知を出さない
```

## 注意事項

- 標準機能がファイルを取り込み中（「Ingesting file」通知の表示中）は実行できません。取り込み中のコレクションを誤って削除しないためです。
- 削除には標準機能と同じ `/api/vector/purge` を使用するため、そのファイルのコレクションは **全ての埋め込みソース・モデル分** が削除されます。
- Vector Storage の「Translate files」が有効な場合、翻訳結果を再現できないため判定は「設定不一致」になります。
- チャットメッセージと World Info のベクトルは標準機能が差分同期で自動修復するため、対象外です。
